# 🚀 Webアプリケーション開発プロジェクト

プログラミング学習者向けのモダンWebアプリケーション開発環境です。

## 📋 技術スタック

- **フロントエンド**: React 18 + TypeScript
- **ビルドツール**: Vite (Rolldown powered)
- **スタイリング**: Tailwind CSS v4 + Shadcn UI
- **バックエンド**: Firebase + n8n

## 🛠️ セットアップ

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```

ブラウザで `http://localhost:5173/` を開いてアプリケーションを確認してください。

### 3. ビルド
```bash
npm run build
```

## 🎯 学習ポイント

### 編集可能なファイル
- **[`src/App.tsx`](src/App.tsx)**: メインコンポーネント
- **[`src/index.css`](src/index.css)**: グローバルスタイル
- **[`src/components/`](src/components/)**: UIコンポーネント

### カスタマイズ例
- Tailwind CSSクラスを変更してスタイルを調整
- Shadcn UIコンポーネントを追加してリッチなUIを構築
- 新しいコンポーネントを作成してアプリケーションを拡張
